위치: /docs/approval-policy.md
역할: 승인이 필요한 작업과 기준 정의

1. 승인 불필요 작업
   - 노션 조회·분석, 보고서 작성
   - 트리거 키워드 기반 일정 등록 (정책 결정에 따라 변경 가능)
2. 승인 필요 작업
   - 메일 초안 작성·발송
   - 구글 파일 생성·업로드
3. 금지 작업
   - 노션 항목 삭제, 파일 삭제, 공유 범위 변경, 비밀값 노출
4. 승인 절차
   - 실행 계획 제시 → 사용자 "승인" 응답 → 계획 상태 변경 → 실행
5. 승인 유효 범위
   - 승인은 해당 계획 1건에만 적용, 재사용 금지
6. 승인 기록 방법 (workspace/plans/, workspace/logs/)
