[docs/trigger-rules.md 개요]
위치: /docs/trigger-rules.md
역할: 트리거 입력 문법과 파싱 규칙 정의

1. 기본 문법
   - "키워드:내용" (예: 개인:친구와 카페약속)
2. 구분자 규칙
   - 인식할 구분자 목록 (예: ":", "：")
   - 앞뒤 공백 처리
3. 내용 파싱 규칙
   - 제목 추출
   - 날짜·시간 표현 해석 (오늘, 내일, 토요일, 3시, 15:00 등)
   - 날짜 미기재 시 기본 처리
4. 여러 건 동시 입력 규칙 (쉼표·줄바꿈 구분 여부)
5. 키워드 매칭 규칙
   - 완전 일치 우선, 대소문자·공백 무시 여부
6. 키워드 미일치 시 처리
   - 등록하지 않음 → 유사 키워드 제안 또는 재질문
7. 예시 모음 (정상 입력 / 오류 입력)
