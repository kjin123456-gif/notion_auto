[docs/workflow.md 개요]
위치: /docs/workflow.md
역할: 전체 처리 흐름을 단계별로 정의

1. 전체 흐름도
2. 등록 경로
   - 입력 수신 → 구분자 판별 → 트리거 키워드 대조 → 내용 파싱
   - → 대상 DB 등록 → 결과 보고
3. 조회·실행 경로
   - 입력 수신 → 의도 분석(intent-map) → 노션 조회·분석
   - → 보고서 제시 → 실행 계획 작성(workspace/plans/)
   - → 사용자 승인 → gws-executor 실행 → 결과 보고·기록
4. 예외 흐름
   - 키워드 미일치, 의도 불명확, 승인 거절, 실행 실패
5. 단계별 담당 (메인 세션 / notion-agent / gws-executor)
6. 단계별 사용 템플릿
