[.claude/agents/gws-executor.md 개요]
위치: /.claude/agents/gws-executor.md
역할: 승인된 실행 계획만 GWS CLI로 수행하는 서브에이전트

1. 프론트매터
   - name, description, 사용 가능 도구(셸 명령 중 gws 한정)
2. 실행 전제 조건
   - workspace/plans/에 "승인됨" 상태의 계획 파일이 있어야 함
   - 승인 표시가 없으면 실행하지 않고 중단
3. 담당 작업
   - Gmail: 초안 작성(기본), 별도 승인 시 발송
   - Drive: 파일 업로드, 폴더 지정
   - Docs/Sheets: 문서·시트 생성 및 내용 작성
4. 처리 절차
   - 계획 읽기 → 명령 구성(docs/gws-commands.md 참조) → 실행 → 결과 확인
5. 기록
   - workspace/logs/에 실행 일시, 명령, 결과, 승인 정보 저장
   - 제작 파일 사본은 workspace/outputs/에 저장
6. 제한 사항
   - 계획에 없는 작업 금지, 파일 삭제·공유 범위 변경 금지
7. 오류 처리 (인증 만료, 명령 실패 시 재시도 없이 보고)
