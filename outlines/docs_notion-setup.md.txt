[docs/notion-setup.md 개요]
위치: /docs/notion-setup.md
역할: 사용자가 노션에 직접 만들어야 할 DB 안내서

1. 준비할 DB 목록
   - 트리거 DB (필수, 1개)
   - 일정표 DB (개인일정표, 업무일정표 등 자유롭게 추가)
2. 트리거 DB 속성 정의
   - 트리거 키워드(제목), 대상 DB(링크 또는 관계형), 기본값, 활성(체크박스), 설명
3. 일정표 DB 권장 속성
   - 제목, 날짜, 상태, 분류, 메모, (업무용) 담당자·마감일
4. 작성 규칙
   - 키워드 중복 금지, 공백·특수문자 사용 자제
   - 새 일정표 추가 시 트리거 DB에 한 줄 추가
5. 노션 연결 권한 설정 방법 (통합 연결, 페이지 공유)
6. 작성 예시 표
7. 설정 후 /sync-triggers 실행 안내
