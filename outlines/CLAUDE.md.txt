[CLAUDE.md 개요]
위치: /CLAUDE.md
역할: Claude Code가 매 세션 가장 먼저 읽는 프로젝트 최상위 규칙 문서

1. 프로젝트 목적
   - 노션 DB 기반 일정 등록·조회, 승인 후 GWS CLI로 후속 작업 수행
2. 입력 분류 규칙 (최우선)
   - 1순위: "키워드:내용" 형식 → 트리거 DB 조회 → 등록 경로
   - 2순위: 키워드 없는 자연어 → intent-map 참조 → 조회·실행 경로
   - 판단 불가 시: 추측하지 않고 사용자에게 재질문
3. 경로별 처리 흐름 요약 (상세는 docs/workflow.md 참조)
4. 역할 분담
   - notion-agent: 노션 조회·등록·분석
   - gws-executor: 승인된 계획만 실행
5. 승인 원칙 (상세는 docs/approval-policy.md 참조)
   - 메일 발송, 파일 생성·공유 등 외부 작업은 반드시 승인 후 실행
6. 참조 문서 목록 (docs/, templates/, config/)
7. 금지 사항
   - 승인 없는 메일 발송, 노션 항목 삭제, 비밀값 출력
8. 응답 언어·보고 형식 규칙 (한국어, templates 양식 사용)
